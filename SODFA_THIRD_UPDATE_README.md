SODFA - Third Update

Changes included in this version:
1. Storefront product showcase now treats parent products and active variants as equal catalog cards.
2. The home product showcase carousel includes both parent products and variants.
3. The product-image marquee includes images from parent products and variants.
4. Model filtering now shows the matching parent product AND all matching variants when both belong to the selected model.
5. Added a global admin network activity banner at the top of the dashboard. It appears while Supabase save/update/delete/storage/auth requests are running and disappears when the operation finishes.
6. New UI text is bilingual (Arabic / English) and the responsive layouts remain based on the existing mobile-first breakpoints.

No database schema change is required for this update.
No files are deleted by this update.
