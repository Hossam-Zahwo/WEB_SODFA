SODFA — تحديث مراجعة الطلبات (لوحة الإدارة)

التعديلات:
- داخل تفاصيل الطلب تظهر بيانات العميل والعنوان، وكل بند بصورة المنتج واسمه والتفريعة والكمية وسعر الوحدة وإجمالي البند.
- تظهر كمية المخزون الحالية للمنتجات المرتبطة بجدول products عبر stock_quantity، مع تنبيه عند نفاد المخزون أو عدم كفايته.
- أضيف مربع اعتماد لكل بند؛ لا يسمح زر تأكيد الطلب بالعمل قبل مراجعة كل البنود، ولا يسمح به إذا كانت كمية stock_quantity أقل من الكمية المطلوبة.
- تأكيد الطلب يستدعي RPC الحالية confirm_store_order_inventory، ولا يخصم المخزون بمجرد وصول الطلب.
- الإشعارات داخل لوحة الإدارة فقط: زر تفعيل يطلب إذن إشعارات المتصفح ويشغّل صوت اختبار، ثم إشعار وصوت عند رصد طلب جديد أثناء فتح لوحة الإدارة/عملها في الخلفية.

مهم بخصوص الإشعارات:
هذه النسخة تستخدم Notification API وSupabase Realtime/polling داخل صفحة الإدارة. لا تتطلب مكتبة إضافية لإشعارات المتصفح الأساسية. لكنها لا تضمن إشعارًا بعد إغلاق الموقع أو قتل المتصفح على الموبايل. لتحقيق Web Push موثوق بالخلفية/بعد إغلاق الموقع، يلزم Service Worker + Push API/مزود مثل Firebase Cloud Messaging أو Web Push server، مع إعداد مفاتيح عامة/سرية وendpoint آمن؛ لا يمكن إكمال ذلك من الواجهة وحدها.

ملاحظات مخزون:
- قراءة المخزون تعتمد على products.stock_quantity. إذا كان مخزون التفريعات محفوظًا في جدول variants منفصل، يجب ربط variant_id بجدول التفريعات وتعديل دالة SQL confirm_store_order_inventory لتخصم من مصدر المخزون الصحيح.
- مربع اعتماد البند هو خطوة مراجعة قبل تأكيد الطلب ككل؛ دالة قاعدة البيانات الحالية تخصم الطلب وفق منطقها الحالي، وليس خصمًا جزئيًا لبنود مختارة.
