# SODFA — تحديث واجهة جزئي

- تم تعديل محرر الهيرو بحيث يظهر **حقل رفع واحد فقط للصورة في وضع الموبايل** لكل سلايد، بدل إظهار رفع صورة الديسكتوب بجواره. عند عدم تخصيص صورة للموبايل يستعمل السلايد صورة الديسكتوب كبديل.
- معاينة صور الهيرو أصبحت تعرض الصورة كاملة `object-contain`، مع الحفاظ على لوحة الألوان الحالية.
- تم تحسين تنسيق صور ومكونات محرر المنتجات دون تغيير قواعد البيانات.
- صفحة المنتجات الحالية تدعم بالفعل منتج عادي/متفرع، وتعدد صور كل تفريعة، وتوريث حقول من المنتج الأصلي.

## لم يُنفّذ بعد
- استيراد Excel جماعي مع فحص ومعاينة ونشر؛ هذا يحتاج تنفيذًا واختبارًا متكاملين مع مخطط Supabase، وليس مجرد زر شكلي.
- إعادة تصميم كل صفحات لوحة التحكم طبقًا للصورة المرجعية بشكل كامل.
- لم يتوفر `package.json` ضمن المصدر، لذا لم يكن ممكنًا تشغيل build واختبار تطبيق متكامل.

## SQL
لا حاجة إلى SQL جديد للتغييرات المنفذة. ملف `SQL_CHANGES.sql` توضيحي فقط.
