# تحديث واجهة SODFA

- تحسين المسافات الداخلية لكروت عرض المنتجات، والمسافات بين المنتجات، والحواف والظلال دون تغيير ألوان الهوية.
- زيادة راحة عرض لوحة التحكم والمسافات الداخلية في محرر المنتجات.
- إضافة اختيار واضح بين «منتج عادي» و«منتج بتفريعات» باستخدام نفس حالة التفريعات ووظائف الحفظ الموجودة مسبقًا.
- الاحتفاظ بمحرر الصور والأسعار والمخزون والتفريعات والربط الحالي مع Supabase.

## SQL
لا يلزم تنفيذ SQL لهذا التحديث؛ لم يتم تغيير أسماء الجداول أو الأعمدة أو سياسات قاعدة البيانات. الاختيار الجديد واجهي ويستخدم `product_variants` الموجود بالفعل.

## تنبيه
الأرشيف الأصلي المرسل يحتوي على مجلد `src` فقط، ولا يحتوي على `package.json` أو إعدادات البناء. لذلك هذا تسليم لمجلد السورس المحدّث، وليس مشروعًا مستقلًا جاهزًا للبناء؛ يجب دمجه في المشروع الكامل. لم يكن ممكنًا تشغيل اختبار build من هذا الأرشيف وحده.
